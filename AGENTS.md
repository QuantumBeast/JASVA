# Project Rules

- **No Virtual Environments**: Do not create or use a Python virtual environment (venv/conda/etc.) for running, testing, or building the application. Always execute Python and PyInstaller commands directly on the local system environment.
- **Zero Clutter UI/UX**: Keep the user interface sleek, minimal, and uncluttered. Never add long descriptive texts, redundant hero banners, duplicate buttons, or wordy status messages. Keep button labels concise (e.g. single words like "MIRROR", "POWER", "HOME") and maintain clean, symmetrical layouts.
